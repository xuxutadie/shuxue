# 新主角：轻量模型与骨骼动画

原始模型只读取，没有覆盖。此版本按用户提供模型的实际身材绑定，制作脚本中的关节坐标仅适用于这个模型。

## 交付文件

- `../../public/world3d/assets/explorer-rigged-v1.glb`：网页、Three.js 或其它支持 glTF 2.0 的软件可用的完整模型，贴图和动画已内嵌。
- `explorer-rigged-v1.blend`：Blender 4.5 可继续编辑的模型、顶点权重、骨骼与动作。
- `base-color.jpg`：2048 × 2048 颜色贴图，已同时打包到上述模型中。
- `report.json`：原始文件哈希和优化结果。
- `verification.json`：重新导入 GLB 后的骨骼、落地和循环检查结果。

## 优化结果

| 项目 | 原文件 | 交付 GLB |
| --- | --- | --- |
| 文件大小 | 81.04 MB | 约 4.01 MB |
| 三角面 | 1,500,000 | 59,999 |
| 贴图 | 3 张 4096 × 4096 | 1 张 2048 × 2048 |
| 骨骼 | 无 | 22 根 |
| 动画 | 无 | Idle（站立）、Walk（原地循环行走） |

使用哑光材质保留主要配色，去除了较重的法线、金属和粗糙度贴图。近距离细节比原模型少，适合网页游戏中的角色显示。

## 查看方式

运行项目后打开 `http://127.0.0.1:8771/world3d/character-preview.html`。
可以切换站立和走路、暂停、调节播放速度、旋转视角，以及显示骨骼。
已接入小镇与星光营地，站立和行走动作根据角色移动状态平滑切换。独立预览保留用于检查动作；原始模型和旧主角文件保留。

## 游戏接入说明

角色身高已统一为 2 个场景单位，原点位于脚下，GLB 中 Y 轴朝上、脸朝 +Z。
按动画名取 `Idle` 与 `Walk`，不要按动画数组第一个元素选择走路动作。
`Walk` 是 1.2 秒的原地循环，以每秒 60 帧制作；由游戏负责前进位移，播放速度需要与实际移动速度协调。
当前版以公开示例的 Walk 动作为参考，按少年角色的骨长重新求解腿部关节。保留脚跟着地、脚掌滚动、脚尖离地和肩胯的错位转动，同时收窄脚距、降低成年参考的身体颠簸。
这是根据动作参考重新适配的版本，不宣称是本项目录制的真人动作捕捉。
走路采用真实蒙皮骨骼，包含髋、膝、踝、脚趾与手臂关节，另有头、颈、脊柱和肩部。
这是基础游戏动作骨架，不包含手指、口型、表情或完整动画师 IK 控制器。
头部与背包权重做了固定处理，减少被手臂牵拉的情况。

## 重新制作

无需额外安装 Python 或网页依赖。使用现有 Blender 运行 `scripts/build-explorer-rig.py`，在 `--` 后传入 `--source` 和原始 GLB 路径。
完成基础绑定后，运行 `scripts/retarget-explorer-walk.py -- --reference artifacts/explorer-rigged-v1/walk-reference.json`，应用当前行走动作。命令前同样需要 Blender 和 `--background --python`。
随后运行 `scripts/verify-explorer-rig.py`，重新导入最终 GLB 验证蒙皮权重、动画首尾、鞋底高度、脚距、重心连续性及脚掌滚动。
脚本失败检查可在 Blender 命令中加 `--python-exit-code 1`。

贴图在浏览器内需要 `blob:` 支持，因此服务器只为 `/world3d` 路径补充了图像与连接的 CSP 许可；普通教学页面仍保持原策略。
