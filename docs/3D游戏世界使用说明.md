# 3D 游戏世界

来源：`E:\网页html\数学思维练习器\online`。迁移了小镇、星光营地、可行走角色、六类操作游戏、原有数学题和面包坊工作台。原项目保持不变，未复制账号数据库、家庭信息、备份或密钥。

## 面包坊剧情样板（本次新增）

- 小镇优先展示“找回营地的星光”第一关，当前任务只有面包师头上的标记。其他 NPC 会先提示去帮助米米。
- 保留原数感题型，用4项准备串起剧情：配对订单、分批装箱、安排20站配送、整理库存。原题库96道题和营地玩法继续保留。
- 每项需完成操作、填对观察数量并算对总数，分别获得10、20、30、30星光；首次整关完成加30，总计120。同一项重复完成不重复发奖，错误不扣分。
- 答错不会直接显示答案，可以重试。主动学习解析后，重试会换成原题库内的同类变式。剧情操作台的摆放和文字草稿约每10秒保存；离开前可点“重试保存”确认。
- 通关播放口粮车配送动画，背包获得口粮箱和信号纸条，下一站指向音乐屋。教师可在游戏足迹中查看所选学生的积分与背包。
- 这一版细化面包坊样板，后续 NPC 仍使用原有数学任务；完整地图主线、装备兑换和其他 NPC 的专属操作剧情待体验后扩展。
- 配置入口为 `server/world3d/adventure.cjs`：章节稳定编号、步骤、奖励与道具分开定义；记录存在现有学生游戏档案的 `adventure.chapters` 中，未新增数据库表，旧作答数据保留。

## 入口与上课方式

- 侧栏“3D 游戏世界”，或“思维游乐场”顶部入口，直接跳转到独立游戏页面，不再内嵌网页。返回课堂前保存草稿；教师可在游戏顶部切换所选学生的进度查看入口。
- 学生沿用现有账号，直接进入小镇体验口粮委托。原6题摸底在数学任务中继续保留，它与小镇48题重合，不额外计数。原48题全部曾提交正确后开放营地；查看解析不算通关。剧情关答对的原题也计入相应题目的通过记录。
- 营地包含铺桥、装车、同步信号、真假线索、双桶量水、路径规划。逐关完成操作开放下一设施，各设施另有8道可选进阶题，共48道。
- 方向键 / WASD 行走，拖动旋转，滚轮缩放，点击地点自动寻路，Enter 交谈。手机可用摇杆。“沉浸模式”进一步放大场景。
- 图形加速不可用时可进入“数学任务”。营地解锁后，即使3D加载失败，下方“开始操作”仍可使用。

- 游戏题不是 AI 生成题，沿用原项目“先作答，再解析”流程。现有 AI 引导练习规则不受影响。

## 游戏内答题与声音

- 小镇与营地默认铺满浏览器窗口，取消外围边框和留白，按钮与摇杆浮在场景上。点击“显示菜单”查看任务和返回课堂；支持的浏览器还可点击“全屏显示”隐藏浏览器栏，再点击“退出全屏”恢复。答题卡、通关弹窗仍显示在游戏画面中。

- 桌面答题卡最大宽度为1080像素，手机按屏幕宽度缩放。最后一题答对并保存成功后，自动结算、收起答题卡，在地图上显示奖杯与彩纸庆祝动画；剧情任务显示星光和下一站提示，普通练习显示“本轮挑战完成”。答错或查看解析时保留反馈，不提前宣布通关。结算连接失败则保留已保存的答题结果，可再次点击继续。

- 小镇数学题、剧情任务和营地进阶题均以游戏场景上的卡片展示。摆放订单、看提示和提交答案只更新卡片，背景场景保留；作答时角色暂停移动。
- 点卡片右上角“收起”或按 Esc，会先保存草稿，再返回所在地图。保存失败会保留卡片和输入。

- 答对、答错和完成剧情有不同提示音，营地操作验证同样有声音反馈。答题时自动降低音乐音量，切到其他标签或离开游戏停止播放。
- 若未听到声音，点击“音乐：点击开启”，并检查浏览器标签和系统音量是否静音；浏览器不允许没有用户操作时自动播放。


## 精简界面与四关教学

### 用语音记录思路

展开答题卡中的“记录我的思路（选填）”，点击“语音输入”，允许麦克风后用普通话讲述，结束时点击“结束说话”。文字追加在原内容后，可以手动修改，随原有草稿一起保存；提交、收起或切换题目前会等待最后一句识别收尾。已提交的记录和教师只读查看不能录入。

录入期间暂时静音背景音乐，不改变音乐开关偏好。最多保留1000字，数字和数学符号请自行检查。网站不保存音频，也不需要额外配置 API Key；识别由浏览器提供，可能使用浏览器厂商的联网服务，需要支持该能力的浏览器、麦克风权限和 HTTPS（本机 localhost 除外）。识别服务不可用时会提示，可继续打字或使用设备自带语音输入，Windows 可按 Win + H。

### 四关内容

默认展示一条当前委托和地图；探索路线、通关进度、提示、思路记录和解法按需展开。每题保留一份完整情境，不再同时展示剧情重复标题与单独的原算式题。

| 关卡 | 学习目标 | 操作后填写 |
| --- | --- | --- |
| 配对订单 | 凑整、加法交换与结合 | 每篮数量、篮数、总数 |
| 分批装箱 | 分组不改变总量、乘法结合律 | 每批数量、批数、总数 |
| 首尾配送 | 相同配对和、成对计数 | 每对数量、对数、总数；奇数项另填单独一项 |
| 整理库存 | 相同单位的合并与拆分、乘法分配律 | 新装与合并盒数，或整批与剩余盒数，再算总数 |

- 服务端逐项核对操作、中间数量和总数。分组可采用不同有效方案，不强制选唯一摆法。
- 答错后，操作台顶部的“修改方案，再试一次”恢复编辑，保留原摆法、观察输入与总数；配满的篮子也可点订单取出再安排。
- 答对后可选择同类迁移题，或继续主线；同一关不重复发星光。看过方法后需换同类题尝试。
- 解法把实物摆放对应到算式；分组题优先解释学生实际选用的分组，再提示比较更好算的组合。
- 观察输入随原游戏草稿保存，提交时记入答题历史，教师可在“游戏足迹”的记录详情中查看。旧成绩、积分与已完成关卡不清空；旧的未完成关卡按新版要求补填观察。

### 主角模型与动作

游戏顶部的“角色”下拉框可以选择男生或女生探险家，小镇和星光营地共用这项选择。学生的选择随账号保存在服务器，刷新或重新登录后保留；旧账号默认使用男生。更换外观不会改变积分、题目、作答次数或通关进度。教师试玩可以选择角色，但仍遵循试玩档案的清理规则；查看真实学生进度时不能代替学生换角色。

两位角色共用站立、走路、跑步、跳跃、坐下和起身六种动作。R 切换走路/跑步，空格跳跃，靠近凳子后按 C 坐下，再按 C 起身；也可点击画面下方按钮。女生按自身身体比例适配骨架，跳跃时张开双臂，坐下时对齐凳子。跳跃、起坐、答题或交谈期间暂不能换角色。新模型加载并保存成功后才替换原角色，加载失败时保留原角色。

男生模型为 explorer-actions-v2.glb，女生模型为 girl-explorer-v1.glb，均约 4 MB。女生原文件约 80 MB，经减面、贴图压缩和骨骼绑定后用于网页；进入地图时只加载所选角色，课堂页面不加载这些模型。旧模型和用户原始文件保留。

两位角色的走路速度为每秒 2.9 个场景单位（原为 2.4），步频同步提高约 20%；跑步为每秒 3.6 个场景单位。跑步时胸肩与骨盆反向转动，肘部随步伐伸屈，重心在支撑与蹬地间起伏。跳跃时双腿自然分开并略微前后错开，落地后恢复站姿。动作预览与游戏共用控制器，预览中的“正常”对应游戏步频。

动作预览入口：/world3d/character-preview.html，可选择角色和六种动作。女生直接预览链接为 /world3d/character-preview.html?character=girl。女生制作工程与验证结果位于 artifacts/girl-explorer-v1，复现方式见其中的使用说明.md。

### 西侧住宅区

小镇西侧新增独立花园住宅区，以步道连接广场。住宅外观扩大，正门朝东面对小镇广场，庭院与步道布置在正门一侧；门前有铺石庭院、花圃、树木和围栏；点击“回家”自动走到新门口，离开室内也回到此处。男女角色分别保留各自的房屋配色与装饰。住宅区边界与房屋、树木、花圃使用同一套行走检测，营地不受小镇扩建影响。

### 东侧星光游乐场

住宅正对面的东侧新增游乐场。点击地图顶部“游乐场”可自动走到入口，在“游乐项目”中选择设施；也可直接点击地图中的设施，角色会先走到上下客点。两位主角均可游玩，不影响数学任务进度。

- 旋转木马：靠近后按 Enter，角色坐上木马旋转两圈，约 24 秒。
- 星光摩天轮：靠近后按 Enter，进入座舱转一圈，约 36 秒；吊舱保持竖直。
- 乘风冲浪：每局 40 秒。方向键左右 / A、D 或屏幕按钮换道，空格 / 跳跃按钮越过浮标。每颗星星 10 分，碰撞损失一次机会，共 3 次机会。

游玩时可以暂停；切换窗口后暂停，点击“继续游玩”恢复。所有设施点击提前结束会立即停止本次游玩，并把角色移到安全入口，不再等待旋转或落地。冲浪结束显示本局成绩，可再玩一次。冲浪得分仅属于本局小游戏，不计入数学测评，也不写入学习积分。

游乐场代码：`playground-rules.mjs` 管理位置和玩法，`playground-model.mjs` 创建模型，`playground.mjs` 处理角色乘坐和界面，`playground.css` 负责操作面板。沿用本地 Three.js，无额外依赖、素材下载或数据库变更。

### 游乐场第二版

旋转木马更换为奶油白小马、马鬃马尾、鞍座缰绳和条纹亭顶，立杆避开人物位置。摩天轮将支架、轮盘和吊舱分层安装，并通过整圈扫描检查座舱之间及座舱与轮盘、支架、地面的间距。

新增彩虹秋千和云朵蹦床，共五项设施：

- 彩虹秋千：乘坐后按空格或“加把劲”增大摆幅，结束时收回到静止位置。
- 云朵蹦床：按空格或按钮起跳；快落到垫面时再次按下可蓄力，成功后下一跳更高。普通落地 5 分、蓄力落地 20 分。提前结束立即回到入口，成绩只属于当前小游戏。

### 星光门票与入口交互

设施上的名称牌已移除。走到设施入口，出现“Enter 游玩 · 20 星光”时按 Enter 即支付并开始；触屏可使用交互按钮。点击设施或菜单中的“前往”只自动走到入口，不会直接扣款。每次重新游玩收费 20 星光，余额显示在画面右上方。提前结束不退回已经使用的门票。

学生的星光扣款保存在已有游戏档案中，无需数据库结构迁移。服务器检查余额、账号权限和消费版本，并利用学生档案行锁避免并发超支；支付响应丢失时重试同一请求不重复扣费。教师查看真实学生时不可消费；教师独立试玩使用隔离的 120 试玩星光，不改变任何学生的余额。冲浪和蹦床的本局分数不兑换为星光。

### 广场长椅与动态喷泉

广场南北两排长椅改为面对面，角色从两排之间走到座位并朝向对面的长椅；点击长椅或靠近后按 C 仍可坐下，按 C 或方向键起身。营地长凳保持原布局。

### 悬浮小岛云层

小镇、住宅区和游乐场外围的云团高低错落，一部分接近并略高于岛面，同时向岛外退让；岛底仅保留几团分散的小云，远处云海也减少，搭配浅蓝至淡紫天空渐变。山谷入口附近留出没有云遮挡的轮廓。云团缓慢漂动，不参与点击、碰撞或阴影，不遮挡岛上道路。营地也有同样的天空氛围。

### 山谷观景入口

山谷入口移到园丁花园与杂货铺之间道路外侧的独立观景平台，与花园拉开距离。入口有高石拱门、双面“山谷探险”字牌、山峰徽章、藤叶及引路灯。点击“前往山谷入口”会沿道路自动走到门前，也可以靠近后按 Enter。仍需完成小镇第一关全部题目才能进入营地；从营地返回会站在新门前。平台边界与石柱参与碰撞。
