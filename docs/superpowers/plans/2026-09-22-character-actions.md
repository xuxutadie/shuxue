# 主角动作实施计划

**目标：** 保留现有形象与行走品质，增加 R 切换跑步、空格跳跃、C 坐下/起身，触屏使用同等按钮。

**已确认设计：** 仅靠近长凳才能坐下；自动走到凳前并转向，臀部对齐座面；按移动键自动起身；跳跃不跨越地图碰撞与关卡限制；答题时停止移动。复用本地 Blender 与 Three.js，无新增依赖、数据库变更或自动提交。

**结构：** 在现有已绑定的 Blender 工程上新增动作并输出独立 v2 模型；使用独立动作控制器统一动画切换，地图继续负责寻路和碰撞。

- [x] scripts/add-explorer-actions.py：从现有 blend 保留 Idle/Walk，制作 Run、Jump、SitDown、StandUp，输出 v2 模型并验证动作、循环和脚底高度。
- [x] public/world3d/hero-actions.mjs：独立状态控制器，平滑切换，跳跃/起坐单次播放，移动先起身，阻止跳跃中再次起跳。
- [x] public/world3d/town3d.js：连接按键/触屏、走跑速度、答题暂停；小镇和营地共用，不修改通关校验。
- [x] public/world3d/character-preview.*：增加全部动作预览，使用相同控制器，便于正侧面检查。
- [x] tests/world3d-assets.test.cjs 及动作测试：验证真实导出文件与状态衔接、输入限制、动画反复切换；浏览器验证按钮、画面和游戏运行。

验收：R 切换而非长按；空格只触发一次跳跃；C 坐下保持，移动时先起身；答题/失焦时不残留方向输入；旧角色与行走资产保留；窄屏按钮不遮挡交谈。

验证结果：全套 153 项测试通过；Blender 重新导入导出文件验证，全部动作无明显穿地，Run 循环顶点误差为 0，起坐接缝匹配。浏览器验证 R 切换、空格跳跃、C 坐下、方向键先起身、答题禁用动作。模型约 3.92 MiB。

2026-09-22 修订：跳跃双臂向两侧展开；拒绝地面坐姿；新增 seats.mjs 管理四张长凳，沿既有寻路抵达凳前；营地凳子统一座高。预览页增加实体长凳。坐姿膝盖约 110 度、小腿自然下垂、两脚间距保持稳定。浏览器已验证远处 C 不会坐下、点击长凳自动落座。
