# 从错题布置变式作业

## 老师操作

1. 在“班级工作台”选择班级、前测或后测，以及对应试卷版本。
2. 点击答题表中的错题格，或展开下方题目，点击“设计变式作业”。系统保留原题版本、完整题干与教师解析，并默认选择该范围内答错或空题的学生。
3. 每份作业编写1～3题。可选基础巩固、同难度变式或拔高，让 AI 生成草稿；也可以手动添加题目。AI 使用现有教师配置与该教师每日题数额度。
4. 逐题核对完整条件、唯一答案、单位和解析。页面会把相较原题改变的文字标红。题目只问一个最终结果；画图、推导和解释在草稿纸或课堂进行，由老师检查。
5. 调整学生名单：可选个别学生、某班或全部班级。可设置截止时间；未设置则不限时间。保存草稿后可从教师侧栏“变式作业”继续编辑。
6. 勾选审核确认，再发布。学生即可收到作业。发布后题目和名单冻结；需要换题时从原题创建另一份作业。

AI 输出仅检查结构和长度，不能保证数学内容无误，所以必须由老师审核。AI 失败不自动发布，也不会以错误题目代替；格式或保存失败会退还本次预留出题额度。已有题目不会被重新生成覆盖。

## 学生操作

进入“练习与错题 → 老师作业”，打开作业后逐题填写答案，点击“检查并保存”。每题第一次提交与后续尝试分别保存，每题最多尝试20次。

所有题至少提交一次即记为完成；完成不等于全部答对，仍可重做巩固。截止后仍可补做，并标记逾期完成。作业不修改原测评分数，也不混入原36道固定练习统计。

提示最多三步：整理条件、选择方法、代回检查。提示由系统提供，不把模型的解析或自由文本直接发给学生。学生接口不返回参考答案、教师解析或原题答案。正式测评进行中，不能读取作业题目、查看提示或提交作业答案。

教师的“学生预览”可以查看已布置作业，但不能保存学生答案或提示记录。

## 看训练效果

教师进入“变式作业”，打开已发布作业，即可查看：

- 完成人数、首次正确率、最近正确率，以及全部变式首次答对的人数。
- 每个学生的原题结果、已尝试题数、首次和最近答对题数、是否逾期。
- 展开学生记录后，查看每次填写的答案、正误、时间和作答前已查看的提示步数。

首次和最近正确率的分母均为已经尝试的题目数，未作答不算零分。原题结果取发布时同版本的测评记录；没有同版本记录会明确标注。老师应结合提示使用情况和学生讲解判断是否真正掌握。

## 保存与部署

新增 `homework` 和 `homework_students` 两张表，应用启动时自动创建；不替换原有课程、测评或学生数据。迁移在事务锁内执行，支持多个服务实例同时启动。没有新增依赖或环境变量。

已发布作业使用原题和变式快照，后续题库调整不会改动它们。学生数据按账号隔离；转到其他教师名下后，旧教师无法读取该生的作业明细，学生也无法读取原教师作业。删除学生账号时，其作业作答记录随账号删除。作业与作答应通过 PostgreSQL 完整备份保存；原“导出学习记录”功能尚不包含新作业记录。

作业列表显示最近100份，较早数据仍在数据库中。变式生成只发送原题、原题图示、参考答案与解析、难度和题数给已配置模型，不发送学生姓名、账号或学生答案。

本地测试使用隔离账号、模拟模型完成教师创建、审核发布、学生作答及教师报告流程；未在验收中调用真实付费模型。上线后使用原有 AI 配置，实际题目质量由老师逐题审核。
