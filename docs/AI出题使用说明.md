# 视频配套题与 AI 引导练习

## 课堂怎么用

1. 先看视频对应的完整母题，再播放视频、操作动画和分析条件。
2. 每道母题都可以单独展开自己的答案与解析。第一课分别展示水瓶茶杯题和橡皮铅笔配套题。
3. 进入变式题时，先读完整题干。红色加粗并带下划线的文字标出变化条件，下方说明具体变在哪里。
4. 让学生先在纸上尝试，再逐题核对；独立练习仍按原流程提交，保留首次作答和重做记录。
5. 从课程练习页、练习与错题页或侧栏进入“AI 引导练习”，选择课程、难度及1～3题。

视频讲过的母题保持相同的情境、条件和解法；变式逐步改变条件，独立题练习迁移方法。原有36道独立练习与40道前后测没有替换，已有记录和版本保持原样。

## AI 规则

- AI 只参与新题的参数规划。题干、可解性及标准答案由服务器的课程模板生成和核验。
- 不提供自由聊天输入，不把模型生成的题干、答案、解法或其他文字直接展示给学生。
- 每题最多3级预先审核的思考提示，只引导读题、画图、比较条件与检查，不给计算结果或完整解法。
- 学生输入自己的答案后，只反馈正确或需要再想；个人历史保存的是学生自己输入的内容，不返回标准答案。
- 同题最多提交20次，达到上限请找老师讨论；获取提示不额外调用模型。
- 前后测仍为独立作答。正式测评进行中，服务器禁止学生生成、读取AI题目历史、获取提示及检查AI答案。
- AI练习单独记录，不计入120分测评和原36题统计。教师可在AI页面选择学生，查看所属学生的题目、已展开提示和每次作答。

## 教师设置

进入“班级与资源 → 配置 AI 接口”，或“AI 引导练习 → 教师 AI 设置”：

| 项目 | 填写说明 |
| --- | --- |
| 接口URL | 服务商提供的公共HTTPS接口，例如 `https://api.openai.com/v1`。支持填写完整 `/chat/completions` 地址，只支持443端口。 |
| 模型名称 | 填写该服务商实际可用、支持Chat Completions文本输出的模型。 |
| API Key | 首次填写完整密钥。保存后不回显；以后留空表示保留。切换到另一个服务商域名时，需要同时填写新密钥。 |
| 每日题数 | 每个账号每天1～100题，默认20。按北京时间零点重置，教师自己的试用单独计数。 |
| 开启开关 | 开启后所属学生可使用；关闭后停止生成、提示和检查，教师仍能只读查看学生历史。 |

先保存，再点击“测试已保存配置”。测试会调用一次服务商接口，可能产生少量费用，但不生成学生记录、不扣学生每日题数。生成新题同样使用该教师配置，学生无需密钥。

兼容协议采用Bearer认证与Chat Completions消息格式，参考 [OpenAI接口文档](https://developers.openai.com/api/reference/resources/chat)。供应商需支持本系统使用的 `model`、`messages`、`stream:false` 与 `max_tokens` 参数；不同供应商模型的兼容性需通过测试确认。

模型请求不发送学生姓名、账号、学习档案或已有答案，仅发送课程编号、难度、题数和随机请求标识。服务器不跟随接口重定向，不允许本机、内网或保留地址。

## 部署到 Zeabur 时新增的设置

本地开发会在已忽略的 `.runtime/ai-encryption.key` 生成仅本机使用的加密材料。生产环境必须另行配置持久的环境变量 `AI_ENCRYPTION_KEY`，值为32字节随机数据的Base64编码；未配置时AI功能保持不可用，其他课程和测评可正常运行。

管理员可在自己的终端运行下列命令，生成一次并妥善保存结果：

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
```

将输出填入Zeabur服务的环境变量 `AI_ENCRYPTION_KEY`，重新部署后再让教师填写服务商密钥。它是数据库中API Key的加密密钥，不是服务商的API Key，不要填写到教师页面。

- 不要每次部署重新生成。加密材料变化后，原API Key无法解密，需要原教师重新保存。
- 数据库备份与加密材料应分别妥善保存。恢复数据库时要使用相同加密材料。
- 新建四张AI专用表，应用启动时幂等创建；不迁移或删除原有学生和成绩。
- “导出学习记录”保留原来的教学导出范围；完整AI记录及加密配置包含在PostgreSQL完整备份中。
- 日额预留在数据库中原子更新，连击不会重复调用模型；正常失败会退回额度，进程中断的预留额度过期后由下次出题回收。
- 历史页面最多展示最近100道AI题，早期记录仍保存在数据库。

## 本轮验证与范围

已完成课程题卡、接口权限、密钥加密、题目构造、失败回退、并发限制、考试拦截和UI状态测试。模型调用使用模拟响应进行验证，尚未使用真实付费服务商密钥联调。

本地隔离浏览器验收使用 `tests/ai-browser-fixture.cjs`，固定绑定127.0.0.1:8772，使用独立测试数据库与模拟模型；生产启动不会载入该文件。正式本机预览运行在127.0.0.1:8771。

上线后需要设置加密材料、教师API Key并测试实际模型连通性；代码推送成功不代表服务商接口已配置完成。
