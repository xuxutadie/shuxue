# 第三张地图：云海天文城

## 进入与教学流程

游戏菜单选择“云海天文城”。真实学生须完成小镇全部题目和营地六站修复；教师独立试玩可直接进入全部地图，不改变任何学生档案。营地完成后，顶部出现“乘飞艇前往天文城”。点击后角色自动走到岛边码头，再选择“登艇出发”。飞艇带着当前角色升空、穿过云海并在对岸降落，空中动画合计约3.5秒，上下艇另计；可以跳过动画。天文城的“前往返航码头”使用同一往返流程。

任务顺序为：飞艇码头 → 星灯长廊 → 齿轮工坊 → 镜光花园 → 气象观测台 → 中央天文塔。每站三项挑战，只显示当前站的黄色任务标记。

| 站点 | 学习目标 | 操作 |
| --- | --- | --- |
| 飞艇码头 | 两侧等量消去、平均分组 | 同时移走配重，分组并校准单罐重量 |
| 星灯长廊 | 循环规律与余数 | 设置连续三盏指定位置的星灯颜色 |
| 齿轮工坊 | 找第一次共同周期 | 调整时间，观察多个齿轮的标记 |
| 镜光花园 | 追踪方向和直角转弯 | 旋转镜面，将光线送到接收器 |
| 气象观测台 | 假设、真假判断、排除 | 选择信号来源并标记每条记录真假 |
| 中央天文塔 | 有序尝试、避障与不同路线 | 经过补给点，绘制一条或两条不同路线 |

答错后可继续调整、撤回或重新设计。每项首次通过分别奖励10、20、30星光；六站全部修复另奖励60星光，最多420星光。重复提交不重复发奖。每站完成后自动收起卡片，展示庆祝动画；设施会恢复运转。

“我的游戏足迹”可查看任务尝试次数、首次答对的次数和最近30次方案。教师从原有“查看所选学生进度”入口进入，只有查看权限。学生进度保存到原有个人数据库档案；教师试玩按账号隔离，沿用现有一小时临时存档机制。

## 后续维护

- `server/world3d/observatory.cjs`：18项任务、服务端判题、顺序解锁、奖励与记录。
- `public/world3d/observatory.js`：答题卡与可操作的SVG演示。
- `public/world3d/observatory-model.mjs`：原生Three.js场景、设施修复效果。
- `public/world3d/observatory.css`：答题卡样式。
- `public/world3d/airship-model.mjs`：可乘坐的飞艇模型。
- `public/world3d/airship.mjs`、`airship-journey.mjs`：码头、登艇、飞行、降落与下艇；只影响画面与落点，不修改学习数据。
- `server/world3d/routes.cjs`：复用账号权限、事务和学生行锁。

存档位置为学生 `data.world3d.observatory`，兼容没有此字段的旧存档。没有增加依赖包或数据库表。新地图复用已有角色动作、碰撞区域与六站落点，不改变原地图的通关条件。

新增同类题时，应保留已发布题目的ID和含义；直接改变已通关题目的答案会使旧进度含义不一致。扩大站点数量时还需同步场景落点、通关统计和碰撞范围，不能只追加题目数组。

## 验证

`node scripts/local-runtime.cjs test` 包含本机数据库测试。`tests/observatory.test.cjs` 验证全部关卡可解、重试与重复提交、奖励总额、旧档兼容和账户隔离；`tests/world3d.test.cjs` 另验证接口权限、数据库并发和教师查看结果。
