# 思维实验室 · 五年级数学

## 当前在线版

基于 Node.js 22 及以上、Express 和 PostgreSQL，提供独立师生账号、班级管理、12节课程、讲解视频、SVG互动活动、小老师讲堂、36道练习、错题和成长报告。课程内容通过项目文件维护，账号与学习记录保存在数据库。

前后测各20道填空题，每题6分，满分120分，45分钟。新开始的前测使用v3题库，后测使用v2；已有作答保留原题库版本。12节课的成片、字幕和封面位于 `public/media/lessons/`，随网站部署。

### 新电脑启动

安装 Node.js 和 PostgreSQL，创建专用数据库，在当前终端安全设置 `DATABASE_URL` 后运行：

```powershell
npm ci
node server/create-teacher.js teacher 老师
$env:PORT = '8771'
npm start
```

访问 http://127.0.0.1:8771 。未指定 `PORT` 时默认8766。首次教师登录信息保存在本机 `.runtime` 目录，登录后需改密；已有账号不会被覆盖。数据库表结构由程序初始化。仓库不包含本机数据库程序、账号、密码或学生数据，新部署需自行配置数据库。

`start-online.ps1` 支持已配置的 `DATABASE_URL`；原电脑也可使用已有 `.runtime` 本机环境。设置开发数据库后运行 `npm test`；原电脑可运行 `node scripts/local-runtime.cjs test`。测试会创建并清理临时测试账号，请使用开发数据库。

以下关于浏览器存储、无后端、未制作视频、教师模式的说明只适用于旧版8765入口，不描述当前在线版。早期验收资料也仅反映当时版本。不要用整个项目目录提供普通静态网站服务。

## 启动

在项目目录右键使用 PowerShell 运行 `start.ps1`，保持窗口开启。在浏览器访问 http://127.0.0.1:8765 。旧入口用于查阅和导出，现由Node文件白名单服务提供。不要再用整个项目目录启动普通静态文件服务器，其中包含本机数据库文件。

始终使用同一浏览器、同一地址及端口。学习记录按网站来源保存，更换端口、隐私浏览或清理浏览器数据都可能导致无法看到原记录。请在教师中心定期导出 JSON 备份。

## 教学与内容边界

试卷参照用户提供的第十四届希望杯五年级第1试的20道填空题结构改编，保留大致题型次序并降低难度。不是官方试卷，不预测未来考纲。两卷为教学设计的平行卷，未经过统计等值验证。部分几何复杂度明显降低，不能用成绩直接推断比赛分数。

默认第一课2026-09-15，最后一课2026-10-22，考试日2026-10-24。10月1日和6日日期可在教师中心调整。前测与后测课内环节各合计120分钟；其他课同样120分钟。

内置的是文字图示分步讲解，**不是已完成的配音视频**。视频播放器支持教师接入可访问的 MP4 / WebM 直链，正式视频需要后续制作；当前不提供实时 AI 对话或自动评价讲课。

教师模式是本地授课操作分区，不是登录或密码安全边界。静态题库随网页分发，学生可通过技术手段读取答案，因此不适用于无人监考的高保密考试。教师应保管后测资料和授课设备。

## 文件结构

- `index.html`：页面入口。
- `styles.css`：界面、移动端和打印样式。
- `data.js`：课程、练习和解析，可独立修改。
- `exams.js`：第二版40道测评题与解析。
- `exam-legacy.js`：旧题库，仅用于历史记录还原。
- `core.js`：存储、校验和计分。
- `games.js`：互动教学活动。
- `app.js`：页面与课堂流程。
- `start.ps1`：本地启动脚本。

所有数据存储于当前浏览器 localStorage，不依赖服务器数据库。不包含注册、云同步、付费功能、视频托管。

## 第二版测评题更新

前后测40道题已全部更换，课堂练习保持原样。已提交的旧记录仍按第一版答案评分。教师在测评中心选择“使用新版重新测评”，确认后原记录归档，再开始第二版试卷。打印和教师答案默认对应第二版。未完成的旧卷继续按原题与原计时完成，避免中途换题。教师控制学生讲评开放的规则不变。
